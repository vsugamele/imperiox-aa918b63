# Documento único de mídias pendentes (PT + EN)

Consolidar os dois briefs antigos (`linfaflow-x1-media-briefs.md` e `-v2.md`) em **um documento bilíngue pronto para uso**, cobrindo tudo que ainda falta gerar para os funis X1 (Messenger/Zernio, WhatsApp e Webchat).

## O que o documento vai conter

Para cada mídia pendente:
- Placeholder exato usado no fluxo (ex. `{{video_hook}}`, `{{video_mecanismo}}`, `{{audio_ritual}}`, `{{audio_inercia}}`)
- Onde aparece (etapa do funil + canal)
- Formato técnico: duração, proporção, legenda, peso máximo
- **Prompt de geração em inglês** (para colar em Veo/Sora/Runway, ElevenLabs, Midjourney/Flux)
- **Prompt/roteiro em português** (versão espelhada para gravação com pessoa real)
- Roteiro palavra-por-palavra dos áudios (EN-US, tom UGC, sem palavras banidas)
- Campo "Cole a URL aqui" para você preencher depois e colar no template

Seções:
1. Como usar / onde colar a URL no editor de fluxo
2. Vídeos (hook, mecanismo, prova, future pacing)
3. Áudios (ritual, inércia, objeção-preço, fechamento)
4. Imagens (antes/depois, comparativo de custo, prova agrupada)
5. Checklist final de compliance (claims, "resultados variam")
6. Tabela de status: placeholder → mídia → URL
