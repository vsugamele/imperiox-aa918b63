O Seedance cobra por segundo — não por clip

O custo por segundo é sempre ~$0.12 independente da duração. Clip de 8s não é mais barato que dois de 4s — custa igual. A vantagem do clip mais longo é menos processamento paralelo e movimento de câmera mais fluido, não economia de custo.

Fase 01

Storyboard com LLM

O Claude Haiku gera o storyboard completo em JSON a partir do brief. Cada cena tem narração, imagePrompt otimizado para o Image-2, motion prompt para o vídeo e tipo (hook/content/proof/cta).

Instrução chave para o imagePrompt

O Image-2 é ruim com texto na imagem. Instrua explicitamente: "SEM texto, palavras ou letras na imagem". O texto vai como headline overlay (Fase 03), não dentro do frame gerado pela IA.

estrutura do storyboard.jsonJSON
{
  "title": "3 erros que impedem iniciantes...",
  "styleBlock": "dark minimal, cinematic, urban professional",
  "scenes": [{
    "id": 1,
    "type": "hook",          // hook | content | proof | cta
    "duration": 5,          // segundos do clip Seedance
    "narration": "...",     // vai para ElevenLabs
    "imagePrompt": "...",   // vai para gpt-5.4-image-2
    "motion": "slow push in", // vai para Seedance
    "headline": "Erro #1",   // texto overlay (sharp)
    "angle": "close"
  }]
}
Fase 02

Imagens com Image-2

O gpt-5.4-image-2 é acessado via /chat/completions — não via /images/generations. A imagem retorna em message.images[], não em message.content.

⚠ Descoberta real — não documentada

O endpoint /images/generations retorna 404 para o gpt-5.4-image-2. Use /chat/completions e leia a imagem em data.choices[0].message.images[0].image_url.url — que é um data URL base64.

gerarImagem() — como funciona de verdadeJS
const { data } = await OR.post('/chat/completions', {
  model: 'openai/gpt-5.4-image-2',
  max_tokens: 100,
  messages: [{ role: 'user', content: `Generate an image: ${cena.imagePrompt}` }]
});

// ⚠ A imagem NÃO está em message.content — está em message.images[]
const dataUrl = data.choices[0].message.images[0].image_url.url;
const b64     = dataUrl.replace(/^data:image\/\w+;base64,/, '');
const buffer  = Buffer.from(b64, 'base64');
fs.writeFileSync(filepath, buffer); // salva PNG
Fase 03

Headlines com sharp

Adiciona texto sobre a imagem gerada pelo Image-2 antes de enviar ao Seedance. A IA não gera texto confiável — fazemos isso programaticamente com a biblioteca sharp.

src/headline.js — overlay de texto na imagemJS
const sharp = require('sharp');

async function adicionarHeadline(imagemPath, texto, outputPath) {
  const img   = sharp(imagemPath);
  const meta  = await img.metadata();
  const { width, height } = meta;

  // SVG com o texto — sharp aceita SVG como overlay
  const svgText = `
    <svg width="${width}" height="${height}">
      <defs>
        <filter id="shadow">
          <feDropShadow dx="0" dy="2" stdDeviation="4" flood-opacity="0.8"/>
        </filter>
      </defs>
      <!-- Faixa semitransparente no terço inferior -->
      <rect x="0" y="${height * 0.72}" width="${width}" height="${height * 0.28}"
        fill="rgba(0,0,0,0.55)"/>
      <!-- Texto centralizado -->
      <text
        x="${width / 2}" y="${height * 0.82}"
        font-family="Arial Black, sans-serif"
        font-size="${width * 0.07}" font-weight="900"
        fill="white" text-anchor="middle"
        filter="url(#shadow)">
        ${texto}
      </text>
    </svg>`;

  await img
    .composite([{ input: Buffer.from(svgText), gravity: 'center' }])
    .toFile(outputPath);

  console.log(`  ✓ Headline adicionada: "${texto}"`);
}

// Uso — aplica em todas as cenas que têm headline
for (const cena of storyboard.scenes) {
  if (!cena.headline) continue;
  await adicionarHeadline(
    `output/frames/cena${cena.id}_${cena.type}.png`,
    cena.headline,
    `output/frames/cena${cena.id}_${cena.type}_headline.png`
  );
}
📐
Posições de headline
Lower third (padrão) — faixa nos 28% inferiores, boa para Reels.
Center — texto no meio, bom para hooks de impacto.
Top — 15% superior, bom quando o sujeito está na parte de baixo.
🎨
Estilos por tipo de cena
hook: texto grande, branco, sem fundo.
content/proof: lower third com faixa escura.
cta: texto em dourado com contorno.
Defina o estilo no campo headlineStyle do storyboard.
Fase 04

ElevenLabs narração

Cada cena tem um campo narration no storyboard. O pipeline envia esse texto para o ElevenLabs e recebe um MP3 que sincroniza com o clip de vídeo na montagem.

Configuração necessária

1. Criar conta em elevenlabs.io (plano gratuito dá 10k caracteres/mês)
2. Copiar a API key em Profile → API Key
3. Adicionar no .env: ELEVENLABS_API_KEY=sk_...
4. Escolher um Voice ID na seção Voice Library do ElevenLabs

src/narration.js — geração de MP3 por cenaJS
const axios = require('axios');
const fs    = require('fs/promises');

const EL_KEY     = process.env.ELEVENLABS_API_KEY;
const VOICE_ID   = process.env.ELEVENLABS_VOICE_ID || 'pNInz6obpgDQGcFmaJgB'; // Adam
const EL_API     = 'https://api.elevenlabs.io/v1';

async function gerarNarracao(texto, outputPath) {
  const { data } = await axios.post(
    `${EL_API}/text-to-speech/${VOICE_ID}`,
    {
      text:           texto,
      model_id:       'eleven_multilingual_v2', // suporta português
      voice_settings: { stability: 0.5, similarity_boost: 0.8, style: 0.3 }
    },
    {
      headers: {
        'xi-api-key': EL_KEY,
        'Content-Type': 'application/json',
        'Accept': 'audio/mpeg'
      },
      responseType: 'arraybuffer'
    }
  );
  await fs.writeFile(outputPath, data);
  console.log(`  ✓ ${outputPath} (${(data.byteLength/1024).toFixed(0)} KB)`);
}

// Gerar narração de todas as cenas em paralelo
await Promise.all(
  storyboard.scenes.map(cena =>
    gerarNarracao(cena.narration, `output/audio/cena${cena.id}.mp3`)
  )
);

Fase 05

Vídeo com Seedance

O Seedance recebe a imagem composta (com headline se houver) como first_frame e o motion prompt descrevendo o movimento de câmera. O prompt do vídeo deve descrever SOMENTE o movimento — nunca venda ou produtos.

Filtro de áudio — como evitar

O Seedance bloqueia prompts com palavras como "entrepreneur", "selling", "business", "money", "marketing". Mantenha o prompt do vídeo descrevendo só o visual e o movimento de câmera. Todo o contexto de negócios fica na narração (ElevenLabs) e na headline (sharp).

Download de clips — requer auth

O campo retornado pelo job completo é unsigned_urls[0], não url. O download precisa do Bearer token no header — não é URL pública.

GET /api/v1/videos/{jobId}/content?index=0
Header: Authorization: Bearer {KEY} · responseType: arraybuffer

Discoveries reais

O que descobrimos testando que não está documentado em lugar nenhum.

🔍
Image-2 não usa /images/generations
O endpoint retorna 404. O modelo roda via /chat/completions normal e a imagem vem em message.images[0].image_url.url como data URL base64.
⏱
Seedance: 4 a 15 segundos
Qualquer inteiro de 4 a 15. O Veo 3.1 é que tem só 3 opções (4, 6, 8). Seedance é muito mais flexível para controle de ritmo de edição.
🔇
Filtro de áudio do Seedance
Palavras de negócios no prompt ativam o bloqueio. Solução: descrever apenas o movimento de câmera. Todo o conteúdo de venda vai na narração e na headline.
📦
Agent SDK precisa Zod v4
O @openrouter/agent exige zod@^4.0.0, não v3. Além disso usa a Responses API (/responses) que o OpenRouter ainda não expôs publicamente.
🔐
unsigned_urls[] não é público
O campo de download é unsigned_urls[0], não url. A URL requer o Bearer token no header — não funciona direto no browser sem auth.
⚡
Paralelizar fase de vídeo
Submeta todos os jobs de vídeo de uma vez com Promise.all. O polling pode rodar em paralelo também. Reduz o tempo de 5 cenas de ~10min para ~2min.
