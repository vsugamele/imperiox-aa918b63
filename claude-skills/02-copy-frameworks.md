# 02 — Copy Frameworks Essenciais

## A. Equação de Valor Grand Slam (Alex Hormozi)

```
            Resultado Desejado × Probabilidade Percebida
Valor  =  ───────────────────────────────────────────────
            Tempo de Espera × Esforço & Sacrifício
```

**4 alavancas — toda oferta forte maximiza numerador, minimiza denominador:**

| Variável | Pergunta-chave | Como aumentar/diminuir |
|---|---|---|
| **Resultado Desejado** ↑ | O que o avatar mais quer no mundo perfeito? | Vender o resultado final, não o produto |
| **Probabilidade Percebida** ↑ | Quão certo ele está de que SEU método funciona? | Prova social + mecanismo + garantia |
| **Tempo de Espera** ↓ | Quanto até o 1º sinal de vitória? | Quick wins na 1ª semana, etapas progressivas |
| **Esforço & Sacrifício** ↓ | Quanta dor/trabalho ele precisa? | Done-for-you, automação, atalhos, checklists |

**Diagnóstico rápido:** se a oferta tá fraca, identifique qual das 4 variáveis tá ruim e ataque essa.

## B. Página de Vendas (PDS) — 14 Blocos

Sequência canônica de página de vendas longa. Use como estrutura quando o usuário pedir "sales page", "página de vendas", "PDS", "landing de conversão".

| # | Bloco | Função |
|---|---|---|
| **B1** | Headline Devastadora | Promessa + Mecanismo + Especificidade |
| **B2** | VSL ou Vídeo Principal + CTA rápido | Convertem early adopters antes de scrollar |
| **B3** | Espelho da Dor | Identificação com situação atual do avatar |
| **B4** | O Grande Erro | Por que tratamentos tradicionais falharam |
| **B5** | A Epifania | Descoberta do novo caminho |
| **B6** | Mecanismo Único | Ciência/lógica por trás do método |
| **B7** | Apresentação do Produto | O que é e pra quem serve |
| **B8** | Conteúdo Por Dentro | Módulos, aulas ou componentes |
| **B9** | Prova Social | Depoimentos e estudos de caso |
| **B10** | Ancoragem & Oferta Principal | Preço com escada de valor |
| **B11** | Stack de Bônus | Entregáveis complementares |
| **B12** | Garantia Incondicional | Risco zero |
| **B13** | FAQ | Quebra de objeções frequentes |
| **B14** | CTA de Fechamento | Decisão binária final |

**Regra estrutural:**
- A cada 3 blocos, repita o CTA (B2, B7, B10, B14).
- Cada bloco precisa de 1 prova mínima (número, depoimento, autoridade, demonstração).
- Headline (B1) deve sobreviver sozinha. Se o avatar ler só B1, já entende a promessa e o mecanismo.

## C. 5 Ângulos de Anúncio (Filemon)

Quando precisar gerar VARIAÇÕES de criativo/copy, rotacione entre os 5 ângulos. Cada um ativa uma camada distinta da psique.

### 1. Raiva / Indignação
**Foco:** apontar o culpado sistêmico (gurus, cursos caros, indústria) que lucra com o erro do lead.
**Gatilho:** *"A indústria de X ganha bilhões te fazendo acreditar em Y. A verdade é Z."*

### 2. Medo / Perda
**Foco:** mostrar o custo financeiro/pessoal de continuar ignorando o problema por mais 6 meses.
**Gatilho:** *"Se você não corrigir [erro] nos próximos 90 dias, vai estar [pior que hoje]."*

### 3. Lógica / Ciência
**Foco:** dados frios, estatísticas, explicação mecânica de por que as outras opções falham.
**Gatilho:** *"Estudo da [autoridade] com [N] pessoas provou que [verdade contraintuitiva]."*

### 4. Status / Reconhecimento
**Foco:** desejo de ser a maior referência da cidade, orgulho de faturar alto, virar a inveja silenciosa.
**Gatilho:** *"Imagina chegar no [evento] sendo o único que [resultado raro]."*

### 5. Curiosidade / Pattern Interrupt
**Foco:** imagem/frase fora de contexto que faz parar o scroll.
**Gatilho:** *"Por que [coisa absurda] é a chave pra [resultado desejado]?"*

**Regra de criativo em escala:** sempre rode 1 anúncio de cada ângulo no mesmo CBO. O ângulo vencedor revela o estado emocional dominante do avatar naquele momento.

## D. Frameworks Auxiliares (use quando couber)

| Sigla | Fórmula | Quando usar |
|---|---|---|
| **AIDA** | Atenção → Interesse → Desejo → Ação | Anúncio curto, email curto |
| **PAS** | Problema → Agitação → Solução | Anúncio direto, bullet de página |
| **4Ps** | Promessa → Pintura → Prova → Push | Email de venda |
| **FAB** | Feature → Advantage → Benefit | Listagem de módulos |
| **BAB** | Before → After → Bridge | Story curta, depoimento estruturado |
| **PASTOR** | Problem → Amplify → Story → Transformation → Offer → Response | Email longo, carta de vendas mid-ticket |
